# 🧮 간단한 Streamlit 계산기 (Simple Calculator)

Streamlit을 활용하여 두 정수와 연산자를 입력받아 결과를 출력하는 웹 기반 계산기 애플리케이션입니다.

---

## 📌 주요 기능
- **입력 기능**: 첫 번째 정수, 연산자(`+`, `-`, `*`, `/`), 두 번째 정수를 각각 입력받습니다.
- **예외 처리**:
  - `+`, `-`, `*`, `/` 외의 잘못된 연산자 입력 시 오류 메시지 출력
  - 정수가 아닌 값이 입력될 경우 오류 메시지 출력
  - `0`으로 나누기를 시도할 경우 오류 메시지 출력
- **결과 출력**: 화면 하단에 계산 결과를 명확하게 표시합니다.

---

## 🛠️ 설치 및 실행 방법

### 1. 필수 라이브러리 설치
프로젝트 루트 디렉토리에서 다음 명령어를 실행하여 필요한 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행
다음 명령어를 입력하여 Streamlit 앱을 실행합니다.

```bash
streamlit run app.py
```

실행 후 브라우저가 자동으로 열리며, `http://localhost:8501` 주소에서 계산기를 이용할 수 있습니다.
